KETENTUAN & LISENSI

Ketentuan Penggunaan, Disclaimer, & Kredit Open Source.

Berlaku untuk situs KY Project serta aplikasi Android/web DompetRumah (com.dompetrumah.app). Terakhir diperbarui: 20 November 2026.

01

Sifat Proyek Non-Profit & Penyediaan "Apa Adanya" (As-Is)

Seluruh aplikasi dan situs di bawah KY Project (termasuk DompetRumah) disediakan gratis tanpa iklan sebagai proyek pribadi/non-profit untuk membantu pencatatan harian. Perangkat lunak disediakan sebagaimana adanya (as-is) tanpa jaminan tersurat maupun tersirat — termasuk kecocokan untuk pembukuan bisnis resmi, audit akuntansi, pelaporan pajak, atau keakuratan tanpa cela. Pengembang tidak bertanggung jawab atas kerugian langsung maupun tidak langsung yang timbul dari penggunaan atau ketidaktersediaan aplikasi.

02

Bukan Lembaga Keuangan & Bukan Nasihat Finansial

DompetRumah hanyalah buku catatan pribadi offline di perangkat Anda. Aplikasi ini tidak menghimpun dana, tidak memindahkan uang antar-rekening nyata, tidak menyediakan kredit/pinjaman, dan tidak memberikan rekomendasi investasi atau nasihat keuangan berizin.

03

Disclaimer Merek Dagang & Non-Afiliasi

Penamaan template atau kategori dompet seperti BCA, BRI, BNI, Mandiri, BSI, GoPay, OVO, DANA, ShopeePay, QRIS, maupun layanan sejenis hanya berfungsi sebagai label pencatatan pribadi pengguna dan memakai lencana huruf umum, bukan aset logo resmi bank/penerbit. KY Project dan DompetRumah tidak berafiliasi, tidak bermitra, tidak disponsori, dan tidak disahkan oleh bank, penyedia dompet elektronik, atau pemegang merek dagang mana pun. Seluruh nama merek dagang tetap menjadi milik pemiliknya masing-masing.

04

Penyimpanan Lokal & Tanggung Jawab Cadangan Data

Seluruh catatan disimpan secara lokal di perangkat Anda (LocalStorage/IndexedDB) tanpa server pengembang. Pengembang tidak memiliki salinan data pengguna dan tidak dapat memulihkan catatan apabila perangkat rusak, aplikasi terhapus, atau cadangan tidak diekspor. Anda bertanggung jawab penuh membuat dan menyimpan file cadangan (JSON/Excel/CSV) secara berkala serta memahami bahwa perangkat dalam kondisi rooted atau tidak terkunci dapat diakses oleh pihak yang memegang perangkat tersebut.

05

Atribusi Sumber Data Kurs (Opsional)

Bila Anda menekan tombol Tarik Online pada fitur multi-valuta DompetRumah, data nilai tukar bersifat referensial (bukan kurs transaksi resmi bank) dan diambil dari penyedia publik berikut:

  • Rates By Exchange Rate API (open.er-api.com — Open Access tier)
  • Fawaz Ahmed Currency API (@fawazahmed0/currency-api via jsDelivr / Cloudflare Pages mirror)
  • Frankfurter API — data kurs referensi European Central Bank (api.frankfurter.app)
